### 🧪 M.Tech Dissertation

**Privacy-Preserving Alzheimer’s Disease Detection for Dynamic Non-IID MRI Data using Federated Learning with FedProx under CKKS Fully Homomorphic Encryption and Stratified K-Fold Cross-Validation**

The dissertation investigated privacy-aware collaborative learning for Alzheimer’s disease MRI classification. The experimental framework explored:

- **Federated optimisation:** FedProx for training across distributed clients.
- **Privacy layer:** CKKS-based homomorphic encryption using TenSEAL for protected model-update operations.
- **Data heterogeneity:** Non-IID client data distributions, including Dirichlet-based partitioning.
- **Evaluation protocol:** Stratified 10-fold cross-validation.
- **Model comparison:** MobileNetV2, EfficientNetB0 and a custom CNN.
- **Evaluation:** Accuracy, precision, recall, F1-score, AUC, ROC analysis and confusion matrices.

The work is an academic dissertation and experimental study; it is not presented as a clinically validated diagnostic product or a published paper.

### ⚛️ B.Tech Dissertation

An academic project exploring quantum gate behaviour and performance in the presence of superposition states using IBM Quantum resources.
